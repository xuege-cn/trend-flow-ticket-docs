# 同花顺弱转强选股公式方案

> **目标**：用同花顺公式筛选弱转强候选股，并从中找出最强势的 20 只。
>
> **核心限制**：同花顺条件选股公式只能输出满足条件的股票列表，不能在公式内部按强度排序并截取前 20。因此需要分两步完成：**先用公式筛出候选池，再在选股结果界面按强度指标排序取前 20**。

---

## 一、整体方案

| 步骤                   | 工具                                  | 产出                                        |
| ---------------------- | ------------------------------------- | ------------------------------------------- |
| **第一步：初筛**       | 同花顺条件选股公式                    | 弱转强候选列表（数量视市场环境，约10—50只） |
| **第二步：排序取前20** | 同花顺选股结果界面（自定义表头+排序） | 相对最强势的20只                            |

---

## 二、第一步：弱转强初筛公式

### 2.1 公式代码

```text

{ 弱转强初筛 - 同花顺条件选股 }
{ 前一日弱势条件：收阴或涨幅极小，且缩量 }
昨日弱势 := (REF(C,1) < REF(O,1) OR ABS(REF(C,1)/REF(C,2)-1) < 0.01)
            AND REF(V,1) < MA(V,20);

{ 今日竞价/开盘转强：高开2%以上 }
今日高开 := O / REF(C,1) >= 1.02;

{ 竞价放量：竞价量占昨日成交量的比例（需同花顺支持DYNAINFO(17)）}
竞价放量 := DYNAINFO(17) > REF(V,1) * 0.08;

{ 开盘后量能确认：当日成交量超过昨日一半（日线周期下的粗略替代） }
早盘放量 := V > REF(V,1) * 0.5;

{ 排除ST、科创板、北交所（按需保留） }
非ST := NOT(NAMELIKE('ST') OR NAMELIKE('*ST'));
非科创 := NOT(CODELIKE('688'));
非北交 := NOT(CODELIKE('8'));

{ 综合信号 }
弱转强信号: 昨日弱势 AND 今日高开 AND 竞价放量 AND 早盘放量 AND 非ST AND 非科创 AND 非北交;

```

### 2.2 公式逻辑说明

| 条件         | 对应逻辑                                        | 作用                             |
| ------------ | ----------------------------------------------- | -------------------------------- |
| **昨日弱势** | 前一日收阴或涨幅小于 1%，且成交量低于 20 日均量 | 确认前一日处于弱势或蓄势状态     |
| **今日高开** | 开盘价 ÷ 昨日收盘价 ≥ 1.02                      | 识别高开 2% 以上的竞价转强       |
| **竞价放量** | 竞价量 > 昨日成交量 × 8%                        | 确认竞价量能达到预设阈值         |
| **早盘放量** | 当日成交量 > 昨日成交量 × 50%                   | 作为日线周期下的盘中量能粗略替代 |
| **排除项**   | 非 ST、非科创板、非北交所                       | 过滤高风险或低流动性标的         |

### 2.3 兼容性说明

1. **`DYNAINFO(17)` 并非所有同花顺版本都能稳定使用。**  
   如果公式报错，可删除“竞价放量”这一行，并从综合信号中移除 `竞价放量`。此时仅依靠“昨日弱势 + 今日高开 + 早盘放量”初筛，候选范围会相应变大。

2. **`SUM(VOL,30)` 不适合直接表示日线下的 30 分钟量能。**  
   在日线周期中，它表示 30 个日线周期的成交量累计。更严谨的做法是在 30 分钟 K 线周期下运行量能公式；本文为方便日线选股，以 `V > REF(V,1) * 0.5` 作为盘中粗略替代。

3. **运行时点会影响结果。**  
   公式应在 9:25 竞价结束后、开盘前运行。此时 `V` 和 `O` 可能是竞价数据，`DYNAINFO(17)` 才有竞价筛选意义；盘后运行时，该函数可能失效，公式也会退化为日线级别筛选。

## 三、第二步：从结果中取“最强势的 20 只”

公式运行后会得到候选列表，需要在同花顺选股结果界面手动排序并取前 20。

### 3.1 操作路径（同花顺 PC 端）

1. 执行条件选股，得到候选列表。
2. 在结果列表的表头区域单击右键，选择“自定义表头”或“管理字段”。
3. 将以下字段加入显示列：
    - **竞价涨幅**（或“开盘涨幅”）
    - **量比**
    - **竞价金额**（或“竞价量”）
4. 单击“竞价涨幅”或“量比”的表头，切换为降序排列。
5. 从排序后的列表中取前 20 只。

### 3.2 排序字段如何选择

| 排序方式         | 主要反映         | 注意事项                                      |
| ---------------- | ---------------- | --------------------------------------------- |
| **竞价涨幅降序** | 竞价价格强度     | 排除高开超过 6%～7% 的标的，避免高开低走      |
| **量比降序**     | 资金抢筹强度     | 量比过高（如大于 10）且大幅高开时，需警惕诱多 |
| **竞价金额降序** | 真金白银的关注度 | 更适合大资金视角，小盘股可能被低估            |

**推荐的实用组合**：先按**量比降序**，再人工剔除竞价涨幅超过 6% 的标的，最后从剩余列表中取前 20。这样既能保留资金关注度，也能过滤部分过度高开的风险。

## 四、必须了解的局限

### 4.1 公式不能替代盘中确认

弱转强策略最大的风险是竞价诱多：9:20 前挂大单制造强势假象，随后撤单；或者高开后立即跳水。

因此，弱转强公式只适合用于**缩小候选范围**。最终决策还应结合开盘后 5～10 分钟的分时承接：

- 价格站稳分时均线、回调缩量：可继续观察或保留。
- 价格跌破分时均线、反抽无量：即使公式选出，也应放弃。

### 4.2 “最强势”没有唯一标准

按量比、竞价涨幅或竞价金额排序，得到的前 20 只可能完全不同。应根据交易风格确定侧重点：

- 重视**资金关注度**：优先看量比和竞价金额。
- 重视**价格强度**：优先看竞价涨幅。
- 希望兼顾两者：先按量比筛选，再结合竞价涨幅人工复核。

公式负责缩小范围，排序方式和最终取舍仍依赖交易者判断。

### 4.3 其他限制

| 局限               | 说明                                                              |
| ------------------ | ----------------------------------------------------------------- |
| **无内置排序截取** | 公式不能直接输出“前 20”，必须在结果界面手动排序                   |
| **版本兼容性**     | 部分版本不支持 `DYNAINFO(17)`，需要使用降级公式                   |
| **周期限制**       | 日线周期下的量能条件只是粗略替代；30 分钟周期更准确，但操作更繁琐 |
| **过拟合风险**     | 2%、8%、50% 等阈值应结合历史回测调整，不宜盲目照搬                |

## 五、完整操作流程速查

```text
1. 9:25竞价结束后，打开同花顺条件选股
2. 运行“弱转强初筛”公式
3. 得到候选列表
4. 右键表头 → 自定义表头 → 加入“量比”“竞价涨幅”“竞价金额”
5. 按“量比”降序排列
6. 人工剔除竞价涨幅超过6%的标的
7. 从剩余列表中取前20只
8. 开盘后5～10分钟观察分时承接：
   - 站稳分时均线、回调缩量 → 保留
   - 跌破分时均线、反抽无量 → 放弃
9. 结合市场环境（涨停家数、炸板率等）决定仓位
```

---

## 六、一句话总结

> 同花顺公式负责初筛弱转强候选（前一日弱势 + 今日高开 + 竞价放量 + 量能确认）；结果界面负责按量比或竞价涨幅排序并人工剔除过度高开的标的。公式只能缩小范围，开盘后的分时承接和仓位管理才是最终决策依据。
