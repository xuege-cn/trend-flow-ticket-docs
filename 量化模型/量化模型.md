## 一、模型总体架构

模型分三层，层层过滤：

| 层级 | 作用 | 核心问题 |
|---|---|---|
| **第一层：环境过滤器** | 决定今天能不能做 | 市场情绪周期允不允许开仓？ |
| **第二层：个股状态分类器** | 判断当前是强势/弱势/弱转强候选 | 这只股票现在处于什么状态？ |
| **第三层：未来走势情景推演** | 基于历史统计给出概率分布 | 类似状态下，历史上后续表现如何？ |

**核心逻辑**：环境决定能不能做 → 状态决定做什么 → 历史统计决定值不值得做、做多少仓位。

## 二、第一层：环境过滤器（市场情绪周期）

> 退潮期再漂亮的个股形态，失败率也明显更高。任何个股信号必须先过环境关。

### 2.1 可量化环境指标

| 指标 | 数据来源 | 阈值参考 | 用途 |
|---|---|---|---|
| 涨停家数 | `ak.stock_zt_pool_em()` | 启动期>30，发酵期>60，高潮期>90，退潮期<30 | 判断情绪阶段 |
| 炸板率 | 炸板数/(涨停数+炸板数) | >40%偏弱，25%—40%混沌，15%—25%健康，<15%加速 | 短线接力环境温度 |
| 昨日连板指数涨幅 | 昨日连板股今日平均涨幅 | 维持3%—5%以上偏健康 | 接力赚钱效应 |
| 跌停家数 | `ak.stock_zt_pool_dtgc_em()` | >10家偏危险 | 亏钱效应扩散程度 |

### 2.2 输出

`ENV_SCORE` 取值：

| 取值 | 含义 | 操作建议 |
|---|---|---|
| **进攻** | 情绪健康，赚钱效应扩散 | 可正常开仓 |
| **中性** | 情绪混沌，分化明显 | 降低仓位，只做最强 |
| **防守** | 退潮期，亏钱效应扩散 | 空仓或极小仓试错 |

### 2.3 数据获取示例

```python
import akshare as ak

zt = ak.stock_zt_pool_em(date="20260101")        # 涨停池
zb = ak.stock_zt_pool_zbgc_em(date="20260101")    # 炸板池
dt = ak.stock_zt_pool_dtgc_em(date="20260101")    # 跌停池

# 炸板率
zhaban_rate = len(zb) / (len(zt) + len(zb))

# 情绪阶段判断（简化）
if len(zt) > 90:
    env = "高潮期"
elif len(zt) > 60:
    env = "发酵期"
elif len(zt) > 30:
    env = "启动期"
else:
    env = "退潮期"

# 综合 ENV_SCORE
if zhaban_rate > 0.40 or len(dt) > 10:
    ENV_SCORE = "防守"
elif zhaban_rate > 0.25:
    ENV_SCORE = "中性"
else:
    ENV_SCORE = "进攻"
