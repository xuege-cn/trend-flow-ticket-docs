# 量比分析完整指南

> 量比是衡量**当前成交活跃程度相对于过去几天同期平均水平**的指标。它回答的是“今天这会儿的交易热度，比平时放大了多少倍”，**不回答方向**。方向看价格，强度看量比，两者必须同时满足才有意义。

---

## 一、量比的定义与计算

### 1.1 公式

**量比 = 当前每分钟平均成交量 ÷ 过去5个交易日每分钟平均成交量**

盘中实时计算：

- 分子 = 开盘至今总成交量 ÷ 开盘至今的分钟数
- 分母 = 过去5日总成交量 ÷ 过去5日总交易分钟数（通常按每日240分钟计）

收盘后看到的量比，就是全天成交量与过去5日平均全天成交量的比值。

### 1.2 量比代表什么

- 量比 = 1：当前活跃度与过去5日平均水平一致
- 量比 > 1：当前成交比平时活跃
- 量比 < 1：当前成交比平时冷清

量比反映的是**相对活跃度的变化**，剔除了不同股票盘子大小、不同时段交易量自然波动的干扰，适合横向比较。

### 1.3 量比和成交量的区别

|            | 成交量           | 量比                   |
| ---------- | ---------------- | ---------------------- |
| 性质       | 绝对量           | 相对量                 |
| 回答的问题 | “今天成交了多少” | “今天比平时活跃多少倍” |
| 用途       | 看规模           | 看异动程度             |

## 二、量比数值区间与含义

不同来源的区间划分略有差异，综合整理如下：

| 量比区间     | 状态     | 一般含义                                                       |
| ------------ | -------- | -------------------------------------------------------------- |
| **小于 0.5** | 极度缩量 | 无人问津，交投清淡，不适合短线参与；除非处于极端磨底阶段       |
| **0.5—0.8**  | 明显缩量 | 比平时冷清，资金关注度低                                       |
| **0.8—1.5**  | 正常水平 | 与过去几天差不多，无大资金异动，以看趋势为主                   |
| **1.5—2.5**  | 温和放量 | 开始有资金关注；低位缓慢爬升偏健康，高位需警惕放量滞涨         |
| **2.5—5**    | 明显放量 | 最值得关注的区间，资金动作明显                                 |
| **5—10**     | 剧烈放量 | 分歧巨大：要么主力强力扫货，要么疯狂出货，需结合位置和分时判断 |
| **大于 10**  | 极端天量 | 大概率是情绪高潮或恐慌极点，次日往往难以为继，警惕天量见天价   |

**注意**：这些区间是参考框架，不是硬标准。小盘股天然量比偏高，大盘股偏低；低位和高位的同一个量比数值，含义可能相反。

## 三、量比的核心原则：方向比数值更重要

### 3.1 量比高 ≠ 强势

这是量比分析中最容易犯的错误。量比只衡量**活跃程度**，不区分这些成交是买方主动吃进还是卖方主动砸出。

| 组合                   | 含义                                             |
| ---------------------- | ------------------------------------------------ |
| **量比高 + 高开/上涨** | 买方主动，资金抢筹，偏强                         |
| **量比高 + 低开/下跌** | 卖方主动，资金出逃，偏弱                         |
| **量比高 + 平开/滞涨** | 多空激烈博弈或对倒，方向待定，需警惕             |
| **量比低 + 高开**      | 缩量高开，可能是惜售，但买盘也不积极，持续性存疑 |
| **量比低 + 低开**      | 缩量低开，抛压不重但买盘更弱，偏弱势震荡         |

**放量低开是量比分析中最典型的陷阱**：量比很高，但方向向下，说明卖方在集中出逃，而不是买方在承接。搜索结果明确指出：“量增价跌：高量比配合股价低开，则需警惕抛压”。

### 3.2 位置决定量比的性质

同样的高量比，低位和高位含义相反：

| 位置 + 量比       | 含义                                                       |
| ----------------- | ---------------------------------------------------------- |
| **低位 + 量比高** | 可能有资金介入吸筹，但需看价格是否同步走强；若低开则偏出逃 |
| **高位 + 量比高** | 警惕主力出货，量比越大风险越高                             |
| **低位 + 量比低** | 无资金关注，参与价值有限                                   |
| **高位 + 量比低** | 可能是高控盘状态，筹码锁定；但若破位需警惕                 |

## 四、量比在分时图中的分析

### 4.1 量比曲线与价格走势的配合

分时图上的量比指标是一条曲线，比成交量柱状图更能反映趋势变化。

| 分时形态                | 含义                                                             |
| ----------------------- | ---------------------------------------------------------------- |
| **量比上升 + 价格上涨** | 放量上涨，买盘主动，健康                                         |
| **量比下降 + 价格上涨** | 缩量上涨，买盘衰竭或跟风不足，警惕回落                           |
| **量比上升 + 价格下跌** | 放量下跌，资金出逃，偏弱，应规避                                 |
| **量比下降 + 价格下跌** | 缩量下跌，抛压衰竭或无人接盘，需结合位置判断                     |
| **量比下降 + 价格横盘** | 缩量横盘，等待方向选择；若守住分时均线可持有观望，放量向下则规避 |

### 4.2 拉升过程中的量比：识别真突破 vs 假诱多

当股价直线拉升时，看量比曲线是否同步：

- **真突破（健康攻击）**：股价创新高时，量比数值同步创新高（例如从3上升到6）。资金越追越多，买力越来越强。
- **假诱多（量价背离）**：股价创新高，但量比曲线反而走低（例如从5掉到3）。只有少量散户在追，主力没跟，大概率冲高回落。

### 4.3 涨停时的量比

- **涨停后量比快速回落**：正常，说明封板成功，主力休息。
- **涨停后量比仍持续上升**：警惕主力借涨停出货，有资金在涨停板上倒货。
- **缩量秒板（量比小于1.5）**：筹码锁定好，但获利盘巨大，一旦大盘跳水容易炸板。
- **换手充分后回封（量比先高后稳）**：开盘量比冲高到5—8，剧烈换手后回落，说明抛压衰竭，此时回封的封死概率较高。

### 4.4 量比在一天中的变化规律

- **开盘时量比最高**：因为分母是全天均量，分子是开盘几分钟的集中成交，量比天然虚高。不要看到开盘量比很大就无脑冲，等回踩分时均线不破再考虑。
- **盘中持续维持在1.5以上**：说明活跃度在延续，不是脉冲。
- **量比快速回落到1以下**：早盘放量只是短暂脉冲，资金没跟上。
- **下午2点后量比天然走低**：如果此时股价还在拉升但量比很低，可能是偷袭尾盘做收盘价，次日出货概率大，不建议追。

## 五、量比在早盘竞价中的分析

### 5.1 竞价量比的含义

竞价阶段的量比反映的是**9:15—9:25的成交量相对于过去5日同时段平均成交量的变化**。量比显著放大（例如大于2或3），说明有资金在竞价阶段积极介入或离场。

### 5.2 竞价量比必须结合竞价价格

| 组合                  | 含义                                                     |
| --------------------- | -------------------------------------------------------- |
| **竞价量比高 + 高开** | 买方主动，资金抢筹，偏强                                 |
| **竞价量比高 + 低开** | 卖方主动，资金出逃，偏弱                                 |
| **竞价量比高 + 平开** | 多空激烈博弈，方向待定，需看开盘后                       |
| **竞价量比低 + 高开** | 缩量高开，可能是惜售或无人卖，但买盘也不积极，持续性存疑 |
| **竞价量比低 + 低开** | 缩量低开，抛压不重但买盘更弱，偏弱势震荡                 |
| **竞价量比低 + 平开** | 冷清，无方向，观望                                       |

**核心**：竞价量比高只说明活跃，方向由竞价涨幅决定。放量低开在弱转强语境下应一票否决。

### 5.3 关注9:20前后的变化

9:20之前可撤单，大单可能是假象。9:20之后不可撤单阶段的量比数据才更真实。特别关注9:24—9:25竞价尾声的量比变化：如果某股昨日弱势、按常理应低开，但竞价最后几秒量比突然放大且股价被抢到平开或小幅高开，是典型的竞价超预期信号。

## 六、量比与换手率的配合

量比看**瞬时爆发力**（短跑冲刺速度），换手率看**全天耐力值**（马拉松配速）。两者配合能过滤假信号：

| 组合                  | 位置     | 含义                                               |
| --------------------- | -------- | -------------------------------------------------- |
| **换手率高 + 量比高** | 低位     | 资金集中介入，吸筹或启动信号                       |
| **换手率高 + 量比高** | 高位     | 出货风险大，量能越猛越危险                         |
| **换手率高 + 量比低** | 任何位置 | 看着热闹但没有新资金进场，可能是存量对倒或主力撤退 |
| **换手率低 + 量比低** | 低位     | 无资金关注，不参与                                 |
| **换手率低 + 量比低** | 高位     | 高度控盘状态，但破位需警惕                         |

一个参考框架（不能机械套用）：

- 换手率 > 5% + 量比 2—3 → 偏启动
- 换手率 5%—10% + 量比 3—5 → 偏主升浪
- 换手率 > 10% + 量比 > 5 → 低位偏吸筹，高位偏出货

## 七、常见问题（FAQ）

**Q1：量比高就代表强势吗？**
不是。量比只衡量活跃程度，不衡量方向。量比高 + 高开/上涨才是强势；量比高 + 低开/下跌是放量出逃，偏弱。你之前遇到的 -8% 低开、量比 4+、收盘 -17% 的票，就是放量出货的典型，不是承接强。

**Q2：量比低就代表弱势吗？**
不一定。低位缩量可能是抛压衰竭或筹码锁定；高位缩量可能是高控盘。量比低本身不构成方向判断，需要结合位置和价格走势。缩量高开在低位有时是惜售，但买盘也不积极，持续性存疑。

**Q3：竞价量比高，今天一定强吗？**
不一定。竞价量比高只说明竞价阶段活跃，方向看竞价涨幅。高开1%—3%配合高量比是健康组合；低开配合高量比是出逃信号；高开超过5%配合极高量比要警惕诱多。

**Q4：开盘量比很大，能直接追吗？**
不建议。开盘时量比天然虚高（计算周期原因），看到开盘量比大就冲容易追在高点。等股价回踩分时均线不破再考虑，或观察开盘后5—10分钟量比是否持续、价格是否站稳。

**Q5：量比和换手率看哪个？**
互补。量比看瞬时活跃度变化，换手率看全天筹码交换充分程度。量比高+换手率低可能是存量对倒；量比低+换手率高可能是全天均匀放量但瞬时无爆发。两者结合看更可靠。

**Q6：尾盘量比突然放大怎么看？**
警惕。尾盘量比放大但股价不涨，可能是做收盘价或对倒，次日出货概率大。高位尾盘放量拉升尤其要警惕诱多。

**Q7：量比大于10意味着什么？**
极端天量，通常是情绪高潮或恐慌极点。低位可能是重大消息或主力集中动作；高位大概率是出货或见顶信号，次日往往难以为继。不建议在量比>10时追高。

**Q8：涨停后量比还在上升，怎么办？**
警惕主力借涨停出货。正常情况涨停后量比应回落（封板成功）；量比继续上升说明有资金在涨停板上倒货，应考虑减仓或离场。

**Q9：量比曲线和成交量柱状图哪个更好用？**
量比曲线是连续变化的，能更直观地看出活跃度的趋势（上升、下降、背离）；成交量柱是离散的。看分时强弱和背离时，量比曲线更灵敏。但两者本质同源，结合使用即可。

**Q10：量比能单独作为买卖依据吗？**
不能。量比必须结合价格方向、股价位置、换手率、板块情绪综合判断。单看量比高低做交易，胜率没有统计优势。有回测显示，单纯按“量比2.5—5买入”的策略长期亏损严重。

**Q11：小盘股和大盘股的量比标准一样吗？**
不一样。小盘股活跃度高，量比天然偏高；大盘股量比5和小盘股量比5的性质完全不同。小盘股靠情绪，大盘股靠机构。关键看相对自身历史水平的变化。

**Q12：量比在低位高、高位低，分别怎么理解？**
低位量比高（尤其配合放量上涨）可能是资金吸筹；高位量比高警惕出货。低位量比低说明无关注；高位量比低可能是高控盘，但破位需警惕。

## 八、量比分析的实用速查
