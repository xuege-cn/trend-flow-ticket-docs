# 选股买入时间节点

> 当前策略均为：**今晚选股 → 明早开盘确认买入**。

---

## 各策略时间节点

### 1. 强势调整战法

| 环节 | 规则                                                                   |
| ---- | ---------------------------------------------------------------------- |
| 选股 | T 日收盘后跑 menu                                                      |
| 买入 | T+1 开盘附近，或开盘 15 分钟内确认不弱再买                             |
| 说明 | 无强制「次日开盘确认」过滤；本质是涨停后整理末端，收盘选出后次日承接买 |

### 2. 深水回拉选股

| 环节 | 规则                                                      |
| ---- | --------------------------------------------------------- |
| 选股 | T 日收盘后进观察池                                        |
| 买入 | T+1 开盘，且开盘涨跌幅 > -3% 才买；开盘继续深水则直接放弃 |
| 说明 | 专防「次日继续砸」                                        |

### 3. 天量长下影选股

| 环节 | 规则                                                                 |
| ---- | -------------------------------------------------------------------- |
| 选股 | T 日收盘后（振幅≥8%、下影≥6%、量能≥4x、收盘位置≥0.75、收盘≥0%） |
| 买入 | T+1 开盘，且开盘 > 0% 才买（必须高开）                               |
| 说明 | 只做强收回 + 次日高开确认；低开说明承接失败，直接放弃                 |

---

## 统一操作习惯

| 动作       | 时间                                            |
| ---------- | ----------------------------------------------- |
| 跑选股     | 每天 15:05–15:30                                |
| 建观察池   | 当晚                                            |
| 真正买入   | 次日 9:25–9:35（看集合竞价 / 开盘是否过确认线） |
| 不过确认线 | 不买，当天作废                                  |

### 开盘确认线一览

| 策略         | 开盘确认条件                     |
| ------------ | -------------------------------- |
| 强势调整战法 | 无强制过滤（开盘附近或不弱即可） |
| 深水回拉选股 | 开盘涨跌幅 > -3%                 |
| 天量长下影选股 | 开盘 > 0%（必须高开）            |
