## 一、核心结论

对生猪养殖企业的经营数据、养殖成本、财务状况和市值规模进行比较后，初步筛选出 **四家** 值得重点研究的公司：

| 研究优先级 | 股票名称 | 股票代码 | 核心逻辑                     |
| ---------: | -------- | -------- | ---------------------------- |
|          1 | 巨星农牧 | 603477   | 成本改善、产能调整、利润弹性 |
|          2 | 神农集团 | 605296   | 养殖成本优势、财务安全性     |
|          3 | 天康生物 | 002100   | 较低养殖成本、产业链协同     |
|          4 | 东瑞股份 | 001201   | 小市值、区域养殖弹性         |

**需要强调：**

- 四家公司并非都已出现明确盈利反转。巨星农牧成本改善信号较明显；神农集团财务结构相对稳健；天康生物仍需观察盈利修复；东瑞股份需重点防范现金流与经营风险。

## 二、为什么寻找这类股票？

本轮研究的核心逻辑：

> 2026 年生猪行业仍处低迷，但前期能繁母猪产能去化可能在 2027 年逐步传导至商品猪供应端。

### 周期时间推演（约 10 个月生产周期）

| 时间窗口        | 观察重点                   |
| --------------- | -------------------------- |
| 2026Q4 — 2027Q1 | 行业可能继续磨底           |
| 2027Q2          | 观察商品猪供应是否明显减少 |
| 2027Q3          | 观察猪价是否出现趋势性改善 |
| 2027Q4          | 验证周期反转能否持续       |

股票市场通常会提前交易未来预期。因此，真正值得寻找的不是已经连续涨停的股票，而是同时满足以下条件的公司：

1. 养殖成本已经开始下降
2. 企业主动调整产能
3. 财务状况能够支撑行业低迷期
4. 2027 年盈利预测有改善空间
5. 当前估值尚未完全反映未来盈利恢复

## 三、四家重点候选公司

### 1. 巨星农牧（603477）

**研究定位**：小市值与成本改善兼顾的周期弹性标的。

#### 基本经营数据

| 指标                      | 数据             |
| ------------------------- | ---------------- |
| 2026 年前三季度生猪出栏   | 320.19 万头      |
| 2026 年 9 月完全成本      | 约 11.92 元/公斤 |
| PSY                       | 31 头以上        |
| 2026 年前三季度归母净利润 | -11.51 亿元      |
| 2026 年三季度末资产负债率 | 72.62%           |
| 2026 年 11 月 19 日总市值 | 约 79.7 亿元     |

#### 主要投资逻辑

1. **养殖成本正在改善**  
   2026 年 9 月完全成本约 11.92 元/公斤，较此前有所下降。若后续继续降本，猪价上涨时盈利恢复速度可能快于高成本企业。

2. **企业主动调整产能**  
   2026 年生产性生物资产较 2025 年底下降 37%，反映企业在做产能调整，而非单纯追求规模扩张。

3. **规模增长仍有空间**  
   前三季度出栏 320.19 万头，具备一定规模基础。

4. **小市值或带来更高股价弹性**  
   相较大型养殖龙头，市值相对较小；若市场提前交易 2027 年猪周期，可能获得更高估值弹性。

#### 主要风险

- 资产负债率 72.62%，财务压力较大
- 前三季度亏损 11.51 亿元
- 行业低迷可能继续消耗现金流
- 市场可能已提前交易部分 2027 年盈利预期

#### 后续重点跟踪

- 完全成本能否降至 11.5 元/公斤附近
- 资产负债率是否停止上升
- 单季度亏损是否继续收窄
- 经营活动现金流能否改善

> **综合判断**：值得重点跟踪，但必须把财务安全放在第一位。

### 2. 神农集团（605296）

**研究定位**：经营质量和财务安全性相对较好的养殖企业。

#### 基本经营数据

| 指标                      | 数据            |
| ------------------------- | --------------- |
| 2026 年前三季度生猪出栏   | 260.41 万头     |
| 出栏同比增长              | 43.5%           |
| 2026 年 9 月完全成本      | 约 11.6 元/公斤 |
| 生产指标 PSY              | 约 31           |
| 2026 年前三季度归母净利润 | -9.71 亿元      |
| 三季度末资产负债率        | 约 46%          |
| 2026 年 11 月 24 日总市值 | 约 174.34 亿元  |

#### 主要投资逻辑

1. **养殖成本具有竞争力**  
   完全成本约 11.6 元/公斤，在行业低迷阶段具有一定优势。

2. **出栏规模增长较快**  
   前三季度出栏同比增长 43.5%，仍具备一定规模扩张能力。

3. **财务结构相对稳健**  
   资产负债率约 46%，低于部分高负债养殖企业，低谷期资金承受力更强。

4. **屠宰业务有助于完善产业链**  
   正在推动养殖与屠宰协同，未来有机会提高产业链价值。

#### 主要风险

- 前三季度归母净利润亏损 9.71 亿元
- 经营性现金流承压
- 出栏快速增长需持续投入资金
- 约 174 亿元市值不算特别小

#### 后续重点跟踪

- 完全成本能否稳定在 11.5—11.6 元/公斤附近
- 出栏增长是否伴随财务压力增加
- 经营性现金流能否恢复
- 屠宰业务能否贡献稳定利润

> **综合判断**：基本面研究价值较高，但需考虑市值与估值是否已提前反映 2027 年盈利预期。

### 3. 天康生物（002100）

**研究定位**：低养殖成本和产业链协同的周期弹性标的。

#### 基本经营数据

| 指标                    | 数据               |
| ----------------------- | ------------------ |
| 2026 年前三季度生猪出栏 | 约 302 万头        |
| 出栏同比增长            | 32.2%              |
| 完全成本                | 约 11—11.6 元/公斤 |
| 前三季度归母净利润      | 约 -5.96 亿元      |
| 资产负债率              | 约 57.23%          |
| 经营活动现金流净额      | 约 4.02 亿元       |
| 经营现金流同比          | -82.91%            |

#### 主要投资逻辑

1. **养殖成本优势**  
   较低完全成本有利于猪价上涨时快速恢复盈利。

2. **产业链布局较完整**  
   覆盖生猪养殖、饲料生产、动物疫苗，业务环节之间有协同空间。

3. **出栏规模增长较快**  
   前三季度出栏同比增长 32.2%，仍具一定扩张能力。

4. **经营活动现金流仍为正**  
   前三季度约 4.02 亿元，虽同比明显下降，但仍然为正。

#### 主要风险

- 前三季度仍然亏损
- 经营现金流同比下降 82.91%
- 资产负债率约 57.23%
- 规模扩张可能带来资金压力

#### 后续重点跟踪

- 完全成本能否保持竞争力
- 季度亏损能否明显收窄
- 经营现金流是否恢复
- 饲料和动保业务是否稳定贡献利润

> **综合判断**：成本优势值得研究，但必须等待利润和现金流改善得到验证。

## 五、2027 年猪周期反转时的利润弹性测算方法

猪周期反转时，核心是测算猪价上涨对企业利润的影响。

不能简单用「出栏量 × 猪价涨幅」，还需考虑：

- 实际商品猪出栏量
- 平均出栏重量
- 销售价格与结算口径
- 养殖成本变化
- 仔猪、饲料及其他费用
- 屠宰、饲料等其他业务损益
- 少数股东损益和所得税

### 简化模型

```
理论增量收入 = 年出栏量 × 单头平均销售重量 × 猪价上涨幅度
```

假设某公司未来年出栏 300 万头、平均销售重量 120 公斤：

| 猪价上涨幅度 | 理论增量收入 |
| -----------: | -----------: |
|    1 元/公斤 |     3.6 亿元 |
|    2 元/公斤 |     7.2 亿元 |
|    3 元/公斤 |    10.8 亿元 |

> **注意**：以上为收入变化的敏感性示例，并非净利润预测。实际净利润还需扣除新增成本、税费及其他业务影响。

## 八、最终投资结论

本轮研究的核心不是寻找已经涨停的猪肉股，而是寻找 **2027 年猪周期反转之前、基本面先出现改善** 的公司。

| 公司     | 研究重点                                   |
| -------- | ------------------------------------------ |
| 巨星农牧 | 成本改善能否持续，高负债是否得到控制       |
| 神农集团 | 经营质量、现金流和估值是否匹配未来盈利增长 |
| 天康生物 | 低成本优势能否真正转化为净利润改善         |
| 东瑞股份 | 小市值优势能否与经营恢复形成共振           |

对于 5 万—20 万元资金、1—6 个月投资周期，不能只根据 2027 年猪周期预期提前重仓，必须同时考虑持有期限、买入估值、资金承受能力和退出条件。

> **最终原则**：优先选择成本持续下降、现金流改善、负债可控、未来盈利预测仍有上修空间的公司。
