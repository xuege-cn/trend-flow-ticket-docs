# A股 AI 产业链投资研究备忘录

> **研究周期**：未来 1—3 年（2026—2029 年）

---

## 一、核心结论

AI 仍是未来几年全球科技产业的重要投资主线，但市场正在从单纯追逐 AI 算力需求，转向更加关注**投资回报、企业盈利和现金流**。

未来 A 股 AI 投资将呈现三个特点：

| 特点         | 含义                                           |
| ------------ | ---------------------------------------------- |
| 产业持续增长 | 全球 AI 基础设施建设仍有较大空间               |
| 行业明显分化 | 有技术壁垒、真实订单和盈利能力的企业更值得关注 |
| 投资逻辑转变 | 从炒作 AI 概念，转向业绩增长与估值匹配         |

**核心策略**：寻找未来 1—3 年业绩能够持续增长、具备竞争优势、估值相对合理的企业。

## 三、未来三年的三条核心投资主线

### 1. 全球 AI 基础设施供应链

**重点方向**

- 光模块、光芯片
- PCB、高速覆铜板
- 存储芯片
- 服务器配套设备

**投资逻辑**：海外大型科技公司的 AI 资本开支，为中国具备全球竞争力的供应链企业带来订单和收入增长机会。

### 2. 国产 AI 算力自主可控

**重点方向**

- 国产 GPU、ASIC、CPU
- 半导体设备
- 芯片设计与先进封装
- 国产算力软件生态

**投资逻辑**：中国 AI 产业发展需要建立自主可控的算力体系，国产替代具有长期战略价值。

### 3. AI 应用与数据中心基础设施

**重点方向**

- AI Agent 及企业软件
- AI 办公、金融、工业应用
- 液冷、电源、配电设备

**投资逻辑**：AI 逐渐从基础设施投资走向实际生产力应用，商业化收入有望成为下一阶段的重要增长驱动力。

---

## 四、未来 1—3 年重点关注的产业变化

| 时间维度    | 主要观察方向                               |
| ----------- | ------------------------------------------ |
| 近期        | 全球 AI 资本开支、光模块、PCB、存储        |
| 未来 1—2 年 | 国产算力芯片、先进封装、数据中心电力与液冷 |
| 未来 2—3 年 | AI Agent、企业软件、AI 商业化              |

> 以上是研究重点，不代表产业发展一定按照严格的时间顺序发生。

---

## 五、投资过程中必须关注的六个指标

| 指标       | 核心问题                           |
| ---------- | ---------------------------------- |
| 营业收入   | 公司业务是否持续增长？             |
| 净利润     | 收入增长是否转化为实际盈利？       |
| 毛利率     | 企业技术壁垒和产品竞争力是否增强？ |
| 订单与客户 | 未来收入是否有可靠支撑？           |
| 经营现金流 | 利润是否真正转化为现金？           |
| 估值水平   | 当前股价是否已经透支未来增长？     |

---

## 六、需要警惕的三大风险

| 风险类型     | 说明                                                       |
| ------------ | ---------------------------------------------------------- |
| 估值风险     | 好公司不一定是好价格，避免追逐过度透支预期的股票           |
| 技术迭代风险 | GPU、ASIC、CPO、液冷等技术路线仍在变化                     |
| 财务风险     | 关注应收账款、库存、资本开支和现金流，防止业绩增长质量不足 |

---

## 七、最终投资观点

未来 1—3 年，A 股 AI 投资的核心不是寻找所有 AI 概念股，而是寻找**真正能够分享全球 AI 产业增长红利的中国企业**。

### 建议优先研究

| 方向        | 关注要点                               |
| ----------- | -------------------------------------- |
| 光模块、PCB | 全球 AI 基础设施建设的直接受益环节     |
| 存储芯片    | AI 训练和推理需求带来的结构性机会      |
| 国产算力    | 具有长期战略价值，但需要验证商业化能力 |
| 电力与液冷  | 数据中心基础设施升级带来的机会         |
| AI 应用     | 关注商业化落地和利润兑现               |

### 投资原则

> 产业趋势决定长期空间，企业竞争力决定盈利能力，估值决定投资回报。

### 最终目标

建立一个覆盖全球 AI 供应链、聚焦 A 股上市公司、每季度跟踪业绩和估值变化的长期研究股票池。
