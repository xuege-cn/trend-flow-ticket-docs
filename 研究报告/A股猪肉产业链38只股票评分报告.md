## 一、评分模型

采用 **100 分制**，五项指标各占 **20 分**。

| 评分维度   |    分值 | 主要考察内容                   |

| 上涨弹性   |      20 | 猪价上涨带来的利润及股价弹性   |

## 八、最终投资结论

针对 **5万—20万元** 资金、**1—6个月** 投资周期，优先研究以下五家：

| 股票     | 核心看点           |
| -------- | ------------------ |
| 牧原股份 | 成本和规模优势     |
| 温氏股份 | 双主业和经营稳定性 |
| 神农集团 | 成本与周期弹性     |
| 天康生物 | 养殖及产业链协同   |
| 巨星农牧 | 养殖规模与成本改善 |

**最终原则**：选择能够活过猪周期、具备成本优势，并且股价尚未完全透支反转预期的企业。
