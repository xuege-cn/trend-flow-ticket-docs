## 一、核心投资结论

养猪股最好的投资时机，通常不是猪价已经大幅上涨、养殖企业已经全面扭亏的时候，而是：

> **母猪产能持续去化，未来供给收缩逐渐得到验证，但猪价和上市公司利润尚未全面反转的时候。**

猪周期投资的本质，是提前交易未来 **6—12 个月** 的生猪供需变化。

### 核心传导逻辑

```text
养殖行业持续亏损
        ↓
能繁母猪产能去化
        ↓
仔猪供应减少
        ↓
未来商品猪供应收缩
        ↓
生猪价格上涨
        ↓
养殖企业利润改善
        ↓
上市公司业绩反转
```

> **股票价格通常领先于现货猪价和上市公司业绩。**  
> 因此，不能等到上市公司利润大幅增长才开始关注养猪股。

## 二、养猪股投资的四个阶段

| 阶段                   | 产业特征               | 股票投资策略       | 投资价值 |
| ---------------------- | ---------------------- | ------------------ | -------- |
| 第一阶段：产能去化     | 母猪持续下降、行业亏损 | 开始研究、分批布局 | 很高     |
| 第二阶段：供给收缩预期 | 仔猪减少、出栏增速下降 | 重点配置           | 很高     |
| 第三阶段：猪价反转     | 猪价持续上涨、亏损收窄 | 持有或择机参与     | 中高     |
| 第四阶段：业绩反转     | 龙头企业全面盈利       | 逐步兑现收益       | 相对降低 |

### 2.1 第一阶段：产能去化期

**主要特征**

- 能繁母猪连续下降
- 养殖行业持续亏损
- 低效率养殖户退出
- 母猪淘汰量增加
- 猪价仍然低迷
- 市场对猪周期普遍悲观

**投资逻辑**

市场通常不愿意在行业亏损严重时给予养殖企业较高估值。但如果未来供给收缩已经开始形成，这反而可能是值得提前研究布局的阶段。

**策略：** 优先研究成本优势明显、现金流较好、负债风险较低的龙头企业。

### 2.2 第二阶段：供给收缩预期形成

**主要特征**

- 母猪产能去化持续
- 仔猪价格止跌上涨
- 新生仔猪数量下降
- 生猪存栏增速放缓
- 商品猪出栏量逐步下降

**投资逻辑**

这一阶段，市场开始意识到未来生猪供应可能减少，养猪股可能开始提前反映未来猪价上涨预期。

**策略：** 这是值得重点关注的配置窗口。

### 2.3 第三阶段：猪价正式反转

**主要特征**

- 全国生猪价格持续上涨
- 商品猪出栏量同比下降
- 猪肉批发价格改善
- 养殖亏损明显收窄

**投资逻辑**

周期反转开始得到现货市场验证，但股价可能已经提前上涨。

**策略：** 关注企业盈利弹性和估值，不盲目追高。

### 2.4 第四阶段：企业业绩反转

**主要特征**

- 生猪价格持续上涨
- 龙头企业实现扭亏
- 季度净利润明显改善
- 市场对猪周期形成一致预期

**投资逻辑**

基本面已经得到充分验证，但股票可能已经提前反映相当一部分利好。

**策略：** 逐步评估估值和未来盈利空间，考虑分批兑现。

## 三、2026年11月猪周期所处位置

根据截至 **2026年11月25日** 能够取得的行业数据：

| 指标                 | 数据                 | 判断           |
| -------------------- | -------------------- | -------------- |
| 三季度末能繁母猪存栏 | 3602 万头            | 明显去化       |
| 能繁母猪同比         | **-10.7%**           | 产能收缩       |
| 三季度末生猪存栏     | 42533 万头           | 同比下降       |
| 前三季度生猪出栏     | 同比 **+1.4%**       | 尚未完全收缩   |
| 前三季度猪肉产量     | 同比 **+3.2%**       | 供应仍有压力   |
| 11月第2周仔猪价格    | 16.92 元/公斤        | 同比下降 30.6% |
| 自繁自养利润         | 约 **-213.95** 元/头 | 仍然亏损       |

### 主要结论

- 母猪产能去化已经发生
- 未来供给收缩的基础正在形成
- 仔猪价格仍然偏弱
- 商品猪出栏尚未同比转负
- 猪价反弹尚未充分证明供需关系反转

> **当前判断：** 处于产能去化向供给收缩预期过渡的阶段。  
> 可以开始研究养猪股，但不宜仅仅因为猪价短期上涨就重仓。

## 四、养猪股的分批买入策略

建议采用三阶段投资方案。下表比例为**示意性仓位分配**，不是必须执行的买入指令。

| 投资阶段         | 示意资金比例 | 买入触发条件                   |
| ---------------- | ------------ | ------------------------------ |
| 第一笔：提前布局 | 20%          | 母猪继续去化，企业估值合理     |
| 第二笔：供给验证 | 30%          | 仔猪价格上涨，出栏增速下降     |
| 第三笔：猪价反转 | 50%          | 全国猪价持续上涨，供给实际收缩 |

### 4.1 第一笔：提前布局（20%）

**关注条件**

- 能繁母猪存栏持续下降
- 行业仍然处于亏损状态
- 龙头企业现金流相对健康
- 企业成本优势明显
- 股价没有提前大幅透支周期预期

### 4.2 第二笔：供给收缩得到验证（30%）

**关注条件**

- 仔猪价格连续上涨
- 仔猪供应同比下降
- 生猪出栏增速明显放缓
- 生猪存栏持续下降
- 养殖亏损进一步收窄

### 4.3 第三笔：猪价反转得到确认（50%）

**关注条件**

- 全国猪价连续数周上涨
- 商品猪出栏同比下降
- 猪肉批发价格同步改善
- 龙头企业盈利预期持续上调
- 股价估值仍有合理空间

> 如果产业数据恶化，应**暂停后续买入**，而不是机械执行仓位计划。

## 八、股票价格与猪周期的关系

养猪股的价格通常**先于**现货猪价和公司业绩变化。

| 产业变化         | 股票市场可能的反应     |
| ---------------- | ---------------------- |
| 母猪产能开始去化 | 资金开始研究养猪股     |
| 母猪持续去化     | 周期预期逐步形成       |
| 仔猪供应减少     | 市场关注未来猪价       |
| 商品猪出栏减少   | 供给收缩逻辑得到验证   |
| 生猪价格上涨     | 养殖股可能进入主升阶段 |
| 龙头企业扭亏     | 市场开始兑现业绩       |
| 行业普遍盈利     | 需警惕周期预期过度一致 |

### 核心原则

> 股票投资买的是**未来预期**，不是已经发生的利润。  
> 但预期也必须有产业数据支撑，不能单纯凭借题材炒作。

## 九、风险控制

### 9.1 产业风险

- 母猪生产效率持续提升，抵消产能去化
- 二次育肥造成短期价格扰动
- 出栏体重持续增加，实际猪肉供应超预期
- 疫病导致生产效率和成本变化
- 猪肉消费恢复低于预期

### 9.2 企业风险

- 养殖成本高于同行
- 资产负债率过高
- 经营性现金流持续恶化
- 大规模扩产造成折旧和财务费用增加
- 股价已经提前反映未来盈利

### 9.3 股票风险

- 周期判断正确，但买入价格过高
- 市场提前交易未来猪价上涨
- 行业反转预期落空
- 市场风格切换
- 大盘系统性风险

## 十一、产能去化周期判断与养猪股投资时机

> **能繁母猪连续下降多久，才能确认猪周期反转？**

| 项目       | 内容                            |
| ---------- | ------------------------------- |
| 研究基准日 | 2026年11月25日                  |
| 研究范围   | 中国大陆生猪产业链及A股养猪企业 |

### 11.1 核心结论

| 连续下降时长                                 | 判断含义                   |
| -------------------------------------------- | -------------------------- |
| 连续下降 **3 个月**                          | 初步确认产能去化趋势       |
| 连续下降 **6 个月**                          | 确认产能持续去化           |
| 连续下降 **9 个月**                          | 未来供给收缩的基础逐渐形成 |
| 连续下降 **9—12 个月**，且仔猪供应下降       | 具备较强的周期反转基础     |
| 商品猪出栏同比转负 + 猪价持续上涨 + 利润改善 | 猪周期反转得到较强确认     |

> **最重要的结论：** 能繁母猪连续下降 **6 个月**，是值得重点关注养猪股的时间节点；但不能单凭母猪下降月份数判断猪周期已经反转。  
> 真正的反转需要母猪、仔猪、商品猪供应和猪价形成相互验证。  
> 以上月份标准属于投资研究中的**经验阈值**，不是官方认定的周期标准。

### 11.2 连续下降不同月份，对应什么阶段？

| 连续下降月份 | 周期判断     | 产业意义               | 股票投资策略       |
| ------------ | ------------ | ---------------------- | ------------------ |
| 1 个月       | 单月波动     | 可能是统计波动         | 暂不判断           |
| 2 个月       | 去化信号     | 产能可能开始调整       | 开始观察           |
| 3 个月       | 初步去化     | 去化趋势初步形成       | 研究龙头企业       |
| 4—5 个月     | 去化增强     | 产能退出可能持续       | 提高关注度         |
| 6 个月       | 持续去化     | 未来供给收缩基础增强   | 重点观察布局       |
| 7—9 个月     | 去化深化     | 仔猪供应可能逐步减少   | 关注反转预期       |
| 9—12 个月    | 反转基础形成 | 商品猪供应逐渐受到影响 | 重点跟踪供给验证   |
| 12 个月以上  | 深度去化     | 供给收缩可能进一步显现 | 结合猪价和估值判断 |

> **注意：** 连续下降月份数需采用**同一统计口径**，最好分别跟踪全国官方季度数据与同一行业机构月度样本数据。  
> **不能**把不同机构的月度数据拼接起来计算连续下降月份。

### 11.3 为什么母猪下降不代表猪价立即上涨？

能繁母猪是生猪产业链的生产源头，但母猪数量减少，并不会马上导致商品猪供应减少。主要有三个原因。

#### 3.1 生产周期存在时间差

母猪减少后，首先影响仔猪出生数量，之后才逐渐影响商品猪出栏。

```text
能繁母猪存栏下降
        ↓
母猪配种及产仔数量减少
        ↓
新生仔猪数量下降
        ↓
仔猪育肥供应减少
        ↓
商品猪存栏减少
        ↓
商品猪出栏下降
        ↓
猪价上涨
```

通常可用约 **9—10 个月** 作为母猪产能变化向商品猪出栏传导的观察周期。具体时间还会受到母猪繁殖效率、仔猪成活率、育肥周期及出栏体重影响。

#### 3.2 PSY 提升可能抵消母猪去化

PSY 指每头母猪每年提供的断奶仔猪数。

例如：假设母猪数量减少 **10%**，但 PSY 提升 **12%**，那么仔猪供应不一定减少。

因此，必须同时观察：

- 能繁母猪存栏量
- PSY
- 母猪窝均健仔数
- 仔猪成活率
- 新生仔猪数量

#### 3.3 出栏体重增加可能抵消头数下降

假设：商品猪出栏数量减少 **5%**，平均出栏体重增加 **6%**，那么猪肉总供应量未必下降。

因此，还要关注：

- 全国生猪出栏均重
- 150 公斤以上大猪占比
- 标肥价差
- 猪肉产量

> 最终应该判断**猪肉实际供应量**，而不只是判断生猪头数。

### 11.4 猪周期反转的四级判断模型

#### 第一级：连续下降 3 个月

**状态：** 产能去化初步确认

**主要条件**

- 能繁母猪连续 3 个月下降
- 同比增速由正转负或降幅扩大
- 养殖行业持续亏损
- 母猪淘汰量有所增加

**投资意义：** 可以开始研究牧原股份、温氏股份、神农集团等养殖龙头；但不宜仅凭三个月下降就认定周期底部已经出现。

#### 第二级：连续下降 6 个月

**状态：** 持续产能去化确认

**主要条件**

- 能繁母猪连续 6 个月下降
- 累计去化幅度逐渐扩大
- 低效率产能退出
- 仔猪供应开始改善或减少
- 养殖企业资本开支趋于谨慎

**投资意义：** 这是值得重点观察养猪股布局机会的阶段，尤其需要研究龙头企业的成本优势、负债和现金流。

#### 第三级：连续下降 9 个月

**状态：** 未来供给收缩基础形成

**主要条件**

- 母猪持续去化
- 新生仔猪数量同比下降
- 仔猪供应减少
- 生猪存栏增速下降
- 商品猪出栏增长明显放缓

**投资意义：** 市场可能开始提高未来猪价上涨的预期。若养猪股估值尚未充分反映周期反转预期，可考虑进一步研究配置。

#### 第四级：连续下降 9—12 个月，商品猪供应同比转负

**状态：** 猪周期反转强确认

**主要条件**

- 母猪持续去化
- 仔猪出生数量下降
- 商品猪出栏同比下降
- 猪肉产量同比下降
- 全国猪价持续上涨
- 养殖亏损持续收窄或实现盈利

**投资意义：** 供给、价格和盈利形成共振，猪周期反转逻辑得到较强验证。

### 11.8 最终投资判断

如果是为了投资 A 股养猪企业，最关注的不是母猪连续下降 12 个月，而是：

> **母猪连续去化 6 个月之后，仔猪供应和商品猪供应是否开始同步收缩。**

**原因**

- 母猪连续下降 3 个月：只能证明初步趋势
- 母猪连续下降 6 个月：说明去化具有一定持续性
- 母猪连续下降 9 个月：未来供给收缩的基础逐渐形成
- 仔猪供应减少：说明产能去化开始向产业链下游传导
- 商品猪出栏同比转负：说明真实供应收缩开始得到验证

**对应股票投资节奏**

| 阶段             | 动作               |
| ---------------- | ------------------ |
| 产能去化阶段     | 开始研究和布局     |
| 供给收缩阶段     | 重点观察配置机会   |
| 猪价反转阶段     | 验证投资逻辑       |
| 业绩全面反转阶段 | 评估估值和兑现收益 |

> **核心原则：** 买在未来供给收缩能够被验证、但市场尚未充分定价的时候，而不是等到猪价大涨、所有企业都开始盈利才入场。
