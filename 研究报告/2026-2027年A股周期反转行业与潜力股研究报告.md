## 一、核心投资思路

本报告**不以股价跌幅**作为主要筛选条件，而是重点寻找真正出现周期反转迹象的行业。

### 理想标的应具备的条件

1. 过去几年经历产能扩张和供给过剩
2. 产品价格持续低迷，企业盈利受到挤压
3. 行业已经开始主动或被动去产能
4. 产品库存出现持续下降
5. 企业毛利率和经营现金流开始改善
6. 未来供需关系有望进一步改善
7. 股票估值尚未完全反映未来盈利修复

### 核心原则

> 优先寻找**基本面先行改善、股价尚未充分反映盈利拐点**的企业，而不是追逐已经大幅上涨的周期股。

### 需要区分的三个阶段

| 阶段     | 含义                       |
| -------- | -------------------------- |
| 周期底部 | 行业处于底部区域           |
| 反转苗头 | 已出现反转迹象，但尚未确认 |
| 上升周期 | 已确认进入上升通道         |

> 三者不是一回事，投资决策前必须先判断行业处于哪一阶段。

## 二、最值得关注的四个行业

### 第一名：白酒行业

#### 1. 行业反转逻辑

白酒行业过去经历了需求放缓、渠道库存增加、批价承压和企业收入增长放缓。

**2026 年开始出现的积极信号：**

- 部分酒企第三季度收入重新转正
- 部分企业现金回款降幅收窄
- 渠道库存逐步调整
- 龙头企业盈利能力仍有一定韧性

但全行业前三季度收入和净利润仍然同比下降，说明目前更接近**底部修复**，而非全面反转。

#### 2. 重点股票

| 股票名称 | 代码   | 重点研究逻辑       |
| -------- | ------ | ------------------ |
| 今世缘   | 603369 | 渠道修复及收入恢复 |
| 迎驾贡酒 | 603198 | 大众消费及区域市场 |
| 口子窖   | 603589 | 库存调整及批价修复 |
| 老白干酒 | 600559 | 区域酒企经营恢复   |

#### 3. 核心观察指标

| 指标     | 反转信号       |
| -------- | -------------- |
| 渠道库存 | 连续下降       |
| 批发价格 | 企稳并持续回升 |
| 终端动销 | 同比改善       |
| 现金回款 | 持续改善       |
| 合同负债 | 恢复增长       |
| 毛利率   | 稳定或回升     |

#### 4. 重点判断

白酒行业的反转核心不是企业降价促销，而是**终端真实需求恢复**。

2027 年春节动销、渠道库存和批价将是重要验证节点。

> **研究结论**：目前有底部修复迹象，值得重点跟踪，但不能认定全行业已经反转。

### 第二名：锂矿及锂电上游

#### 1. 行业反转逻辑

锂矿行业经历了前期价格大幅下跌、供给扩张和盈利恶化。

**近期值得关注的变化：**

- 产业链部分库存下降
- 下游磷酸铁锂排产具有一定支撑
- 储能和新能源汽车需求提供中长期需求基础
- 部分高成本产能对价格的承受能力下降

但矿山复产、供应增加和库存变化仍然可能影响价格。

#### 2. 重点股票

| 股票名称 | 代码   | 重点研究逻辑       |
| -------- | ------ | ------------------ |
| 天齐锂业 | 002466 | 锂资源及锂价弹性   |
| 赣锋锂业 | 002460 | 锂资源布局及产业链 |
| 中矿资源 | 002738 | 锂资源及成本变化   |

#### 3. 核心观察指标

| 指标           | 反转信号       |
| -------------- | -------------- |
| 碳酸锂现货价格 | 连续上涨       |
| 全产业链库存   | 持续下降       |
| 锂盐厂开工率   | 供需改善后回升 |
| 下游排产       | 持续增长       |
| 锂矿供给       | 高成本产能退出 |
| 企业毛利率     | 连续改善       |

#### 4. 重点判断

锂矿行业的关键在于**库存是否真正下降**，以及库存下降能否转化为现货价格上涨。

不能仅凭期货上涨认定行业反转。

> **研究结论**：供需改善值得跟踪，但需要进一步确认现货价格和库存趋势。

### 第三名：氨纶及化纤行业

#### 1. 行业反转逻辑

氨纶行业过去几年受到新增产能释放和产品价格下跌影响。

**2026 年出现的改善迹象：**

- 氨纶价格有所回升
- 行业开工率改善
- 落后产能退出
- 化纤行业前三季度利润同比有所改善

但三季度部分企业盈利环比承压，说明行业复苏仍不稳固。

#### 2. 重点股票

| 股票名称 | 代码   | 重点研究逻辑       |
| -------- | ------ | ------------------ |
| 新乡化纤 | 000949 | 氨纶业务利润弹性   |
| 华峰化学 | 002064 | 氨纶龙头及成本优势 |
| 泰和新材 | 002254 | 氨纶及高性能纤维   |

#### 3. 核心观察指标

| 指标       | 反转信号 |
| ---------- | -------- |
| 氨纶价格   | 持续上涨 |
| 行业开工率 | 稳步提升 |
| 企业库存   | 持续下降 |
| 吨毛利     | 连续改善 |
| 新增产能   | 明显减少 |
| 下游订单   | 持续恢复 |

#### 4. 重点判断

氨纶可能已经率先走出底部，但需要判断产品价格上涨是否真正转化为企业净利润增长。

尤其需要区分：**原材料成本上涨造成的价格上涨** vs **供需改善造成的盈利增长**。

> **研究结论**：已经出现一定盈利修复迹象，值得重点研究。

### 第四名：乳业

#### 1. 行业反转逻辑

乳业此前受到原奶供给过剩、消费需求偏弱和产品竞争加剧的影响。

**2026 年出现的积极信号：**

- 生鲜乳价格连续数月回暖
- 原奶供给开始调整
- 部分乳企经营效率改善
- 乳制品行业收入出现一定恢复

但终端消费需求仍需验证。

#### 2. 重点股票

| 股票名称 | 代码   | 重点研究逻辑           |
| -------- | ------ | ---------------------- |
| 新乳业   | 002946 | 区域乳企及产品结构改善 |
| 光明乳业 | 600597 | 原奶价格及经营效率改善 |

#### 3. 核心观察指标

| 指标           | 反转信号        |
| -------------- | --------------- |
| 生鲜乳价格     | 持续回暖 / 企稳 |
| 奶牛存栏量     | 供给收缩        |
| 原奶供需关系   | 趋于平衡或偏紧  |
| 乳制品终端销售 | 同比改善        |
| 企业毛利率     | 稳定或回升      |
| 经营活动现金流 | 持续改善        |

> **研究结论**：行业价格出现企稳迹象，但终端需求仍然是决定反转持续性的关键。

## 三、暂时不建议作为第一批周期反转投资对象的行业

| 行业   | 当前判断     | 主要原因                         |
| ------ | ------------ | -------------------------------- |
| 多晶硅 | 等待确认     | 库存仍高，供需尚未平衡           |
| 农药   | 继续观察     | 产品价格低迷，盈利改善需要验证   |
| 工业硅 | 等待供给出清 | 供给压力仍然存在                 |
| 造纸   | 暂不确认     | 部分纸种价格仍承压               |
| 制冷剂 | 结构性景气   | 部分产品已经上涨，需警惕估值透支 |

**特别注意：**

- **多晶硅、农药、工业硅**：可能具有较大的周期反弹空间，但股价跌幅大 ≠ 基本面已经出现拐点。
- **制冷剂**：属于另一种逻辑——配额制度约束供给，部分品种已进入景气上行阶段，不应简单按深度周期底部估值。
