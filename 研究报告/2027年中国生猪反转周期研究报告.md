## 一、核心结论

### 主判断

**2026 年末至 2027 年初**：行业可能仍处磨底阶段。  
**2027 年二季度起**：前期母猪产能去化有望逐步传导至商品猪供应端。  
**2027 年三至四季度**：供应收缩可能进一步显现。

> **关键提醒**：2027 年二至四季度是**预测窗口**，不是已经确定的猪价上涨时间。

### 需要区分的四个拐点

| 拐点类型 | 可能时间              | 含义                     |
| -------- | --------------------- | ------------------------ |
| 产能拐点 | 2026 年内至 2027 年初 | 能繁母猪数量下降         |
| 供应拐点 | 2027 年二季度开始     | 商品猪供应逐步收缩       |
| 猪价拐点 | 2027 年二至四季度     | 供需改善推动猪价持续上涨 |
| 股票拐点 | 可能提前数月          | 市场提前交易未来盈利改善 |

其中，**股票拐点最难预测**。对 A 股投资者而言，不能等猪价全面上涨后再研究猪肉股——股价可能已经提前上涨。

## 二、证据一：能繁母猪存栏已明显下降

> 这是判断下一轮猪周期最重要的领先指标。

### 2.1 2026 年三季度官方数据

根据国家统计局 2026 年三季度数据：

| 指标             | 数据      |
| ---------------- | --------- |
| 全国能繁母猪存栏 | 3602 万头 |
| 正常保有量       | 3750 万头 |
| 同比下降         | 10.7%     |
| 二季度末存栏     | 3780 万头 |
| 三季度环比减少   | 178 万头  |
| 环比降幅         | 4.71%     |

**数据来源**：国家统计局；新浪财经 2026年11月4日生猪行业分析。

#### 重要结论

1. 能繁母猪存栏已**低于** 3750 万头正常保有量。
2. 三季度环比下降 4.71%，产能调整速度明显加快。
3. 同比下降 10.7%，说明产能收缩已不是简单短期波动。

#### 为什么重要？

母猪是未来商品猪供应的源头。母猪数量下降 → 仔猪出生可能下降 → 未来商品猪出栏可能下降。

但母猪减少**不会马上**导致猪肉供应减少——此前已出生的仔猪仍会陆续育肥出栏。因此，真正关键的是**时间传导**。

### 2.2 产能去化仍有进一步发展的可能

Mysteel 于 2026年10月13日发布的样本数据：

| 指标                     | 2025年7月   | 2026年9月   |
| ------------------------ | ----------- | ----------- |
| Mysteel 样本能繁母猪存栏 | 527.26 万头 | 478.73 万头 |

累计减少 **48.53 万头**，降幅 **9.20%**。其中：

- 规模化养殖场减少约 41.07 万头
- 中小养殖场减少约 1.71 万头

> **口径说明**：这是 Mysteel 样本数据，与国家统计局全国存栏的统计范围不同，**不能直接混合计算**。

值得关注的是：规模化企业也开始调整母猪产能——行业去化不再只是小养殖户退出，大型企业也在重新调整生产计划。

**判断**：若后续大型养殖企业继续削减低效率母猪，2027 年供应收缩逻辑会更加扎实。

**资料来源**：Mysteel《能繁母猪存栏去化但有限，明年行情不宜过度乐观》，2026年10月13日。

## 三、证据二：产能下降为何不能马上变成猪价上涨

> 这是整份报告最关键的逻辑：生猪生产存在天然的时间滞后。

### 生产周期

| 生产环节           | 时间        |
| ------------------ | ----------- |
| 母猪怀孕           | 约 114 天   |
| 仔猪出生至育肥出栏 | 约 5—6 个月 |
| 配种到商品猪出栏   | 约 10 个月  |

因此：若 2026 年三季度母猪数量明显下降，其对商品猪供应的主要影响通常要到 **2027 年二季度前后**才会逐步体现。这也解释了为何母猪已降、但 2026 年四季度仍可能出现大量生猪供应。

### 3.1 2026 年出栏量仍然增长

根据国家统计局 2026 年前三季度数据：

| 指标             | 2026年前三季度 | 同比  |
| ---------------- | -------------- | ----- |
| 全国生猪出栏     | 53739 万头     | +1.4% |
| 猪肉产量         | 4508 万吨      | +3.2% |
| 三季度末生猪存栏 | 42533 万头     | -2.6% |

**现象**：母猪产能已明显下降，但猪肉产量仍同比增长。

**原因**：前期母猪存栏较高，形成的商品猪供应仍在持续释放；单头出栏重量和养殖效率也会影响总供给。

> **结论**：母猪存栏下降 ≠ 当月猪肉供应下降。必须等待前期高产能形成的商品猪供应逐渐消化。

**资料来源**：国家统计局 2026年三季度生猪生产数据；新浪财经 2026年11月4日生猪供需分析。

## 四、证据三：为何 2027 年二季度可能出现供给拐点

2026 年三季度全国能繁母猪存栏 3602 万头，同比下降 10.7%。多家机构基于「母猪 → 商品猪出栏约 10 个月」的传导周期，给出测算：

### 机构测算一

| 对应出栏时间    | 研究测算的供应变化     |
| --------------- | ---------------------- |
| 2027 年一季度   | 同比下降约 3.4%        |
| 2027 年二季度   | 同比下降约 8.3%        |
| 2027 年三季度初 | 供应收缩有望进一步体现 |

### 机构测算二

若假设 2026 年三季度母猪存栏平均约 3750 万头，对应 2027 年二季度商品猪出栏量可能同比收缩约 **7.3%**。

> **注意**：以上均为机构基于不同假设与模型作出的**预测**，不是国家统计局已公布的未来出栏数据。两组模型的数值与假设并不完全一致，不能直接当作确定事实。

但它们共同指向一个方向：

> **2027 年二季度**，可能是母猪去化开始明显传导到商品猪供应端的重要时间窗口。

**资料来源**：

- 新浪财经行业研究《农产品聚焦：生猪：旺季或难突围，2Q27 或现拐点》
- 东方财富研究报告《生猪养殖 3Q2026 存栏数据跟踪》

## 五、证据四：持续亏损强化产能退出动力

判断猪周期，不能只看存栏，还必须看养殖企业能否持续承受亏损。

### 5.1 当前行业盈利情况

截至 2026年11月20日：

| 指标             | 数据          |
| ---------------- | ------------- |
| 全国生猪出栏均价 | 9.35 元/公斤  |
| 猪肉平均批发价   | 14.73 元/公斤 |
| 自繁自养头均亏损 | 384.61 元     |
| 外购仔猪头均亏损 | 274.27 元     |
| 猪粮比           | 3.91          |

猪粮比仍低于 **5:1** 的一级预警线，说明行业尚未真正摆脱亏损。

持续亏损可能带来：

- 现金流不断消耗
- 低效率母猪被淘汰
- 中小养殖户退出
- 企业扩张计划放缓
- 融资机构更重视养殖企业资金安全

> **但要注意**：大型企业资金实力更强，未必因短期亏损立即退出，产能去化速度可能没有市场预期得那么快。

### 5.2 亏损为何反而可能形成下一轮机会？

猪周期的基本规律：

1. **普遍盈利** → 企业容易扩大生产
2. **持续亏损** → 企业逐渐降低产能
3. **供应减少到一定程度** → 供需关系才有机会变化

这一过程通常需要**数个季度**，而非几周。因此，2026 年持续亏损，是 2027 年供应收缩逻辑的重要基础。

**资料来源**：长城证券 2026年11月生猪周报；2026年11月24日农林牧渔行业周报。

## 六、证据五：2026 年四季度尚不能认定反转

> 对上述乐观判断的反向验证。

截至 2026年11月13日：

| 指标             | 数据         |
| ---------------- | ------------ |
| 生猪出栏均价     | 8.64 元/公斤 |
| 商品猪出栏均重   | 125.87 公斤  |
| 猪肉冻品库容率   | 30.76%       |
| 自繁自养头均亏损 | 446.67 元    |

> 不同机构的周度统计口径与日期略有差异。

这些数据反映出：

- 生猪出栏重量仍处于较高水平
- 冻品库存压力仍然存在
- 行业仍然深度亏损
- 季节性腌腊和春节备货，不一定能改变长期供应过剩

2026年11月19日《中国证券报》亦指出：当前生猪市场仍处于**磨底阶段**。

### 确认反转前需看到的信号

1. 出栏均重持续下降
2. 冻品库存明显下降
3. 能繁母猪去化传导到商品猪供应端
4. 商品猪出栏量持续下降

在这些信号出现之前，**不能把猪价短期上涨当成真正反转**。

**资料来源**：

- 长城证券《生猪周报》，2026年11月15日
- 《中国证券报》2026年11月19日《生猪市场仍处磨底阶段》

## 七、证据六：政策限制无序扩张

2026年5月，农业农村部修订生猪产能调控相关政策，将全国能繁母猪正常保有量调整为 **3750 万头**。

政策方向主要包括：

- 控制不合理的生猪产能扩张
- 优化能繁母猪存栏结构
- 鼓励养殖企业提高生产效率
- 推动行业长期稳定发展

2026年10月，Mysteel 报道提及：农业农村部召开生猪产能常态化精准调控座谈会，并对逆势增加能繁母猪的行为加强调控。

**政策意义**：若价格上涨后企业马上大量扩产，猪周期可能再次供应过剩；限制无序扩张，有利于减少下一轮产能快速反弹的可能。

> **但**：政策目标 ≠ 实际产能一定按目标下降。真正的供应变化仍需通过企业出栏数据验证。

## 八、时间推演：四个阶段

结合生产周期、母猪存栏变化和行业亏损，将未来划分为四个阶段。

### 第一阶段：2026 年四季度 — 2027 年一季度

**判断**：行业磨底，可能出现阶段性反弹。

**重点关注**：

- 能繁母猪存栏是否继续下降
- 仔猪出生数量是否下降
- 生猪出栏重量是否下降
- 冻品库存是否持续去化
- 养殖企业亏损是否收窄

这一阶段最重要的不是猪价涨多少，而是**确认产能是否真的在减少**。若春节前后猪价上涨，但出栏重量和供应量没有下降，仍可能只是季节性反弹。

### 第二阶段：2027 年二季度

**判断**：第一个重要供应拐点观察窗口。

**重点关注**：

- 2026 年三季度母猪去化是否传导到商品猪出栏
- 商品猪出栏量是否同比下降
- 仔猪供应是否持续减少
- 龙头企业是否开始减少出栏压力
- 猪价低点是否逐渐抬高

若这些指标**同时改善**，反转可信度会明显提高；若只有股价上涨，而出栏量、母猪存栏和猪价没有改善，则不能确认基本面反转。

### 第三阶段：2027 年三季度

**判断**：潜在供需改善进一步兑现的阶段。

Mysteel 于 2026年10月的分析认为：前期母猪去化的供应影响，可能在 **2027年7月至9月**集中体现。若符合这一推演：

- 商品猪供应可能进一步减少
- 养殖企业出栏压力可能下降
- 生猪价格可能逐渐脱离底部
- 头部企业利润可能开始改善

> 这是我认为值得**重点跟踪**的阶段。

### 第四阶段：2027 年四季度

**判断**：验证周期反转能否持续。

若前几个季度的供应下降得到验证，四季度需进一步判断：

- 猪价上涨是否具有持续性
- 养殖企业是否恢复盈利
- 能繁母猪存栏是否重新增加
- 企业是否因猪价上涨开始扩产
- 市场估值是否已提前反映未来盈利

> **重要风险**：即使猪价真正上涨，股票也不一定继续上涨——资本市场往往会提前交易周期反转预期。

## 九、三种情景分析

不建议只做一个乐观预测，应同时考虑三种情况：

| 情景     | 发生条件                                     | 可能结果                        |
| -------- | -------------------------------------------- | ------------------------------- |
| 乐观情景 | 母猪持续去化，出栏明显减少，库存下降         | 2027 年二至三季度猪价趋势性上涨 |
| 基准情景 | 母猪去化逐步兑现，但效率提升抵消部分减量     | 2027 年二至四季度温和修复       |
| 悲观情景 | 企业效率继续提升，出栏重量增加，产能去化放缓 | 2027 年仍处磨底或弱势震荡       |

**当前更倾向：基准情景。**

原因：2026 年三季度母猪存栏下降幅度较大，但大型企业规模化程度与生产效率仍在提高，可能抵消部分产能下降影响。因此，不宜简单复制 2019—2020 年那种剧烈猪价上涨。

## 十、如何验证猪周期真的反转

建议建立一张**每月跟踪表**：

| 观察指标         | 重要程度 | 理想变化     |
| ---------------- | -------- | ------------ |
| 能繁母猪存栏     | 极高     | 连续下降     |
| 仔猪出生数量     | 极高     | 同比下降     |
| 商品猪出栏量     | 极高     | 同比下降     |
| 商品猪出栏均重   | 高       | 持续下降     |
| 冻品库存         | 高       | 持续下降     |
| 自繁自养利润     | 高       | 亏损持续收窄 |
| 生猪现货价格     | 高       | 低点逐步抬高 |
| 龙头企业完全成本 | 高       | 持续下降     |

### 判断规则（四步）

| 步骤   | 观察                               | 含义                     |
| ------ | ---------------------------------- | ------------------------ |
| 第一步 | 能繁母猪下降，但出栏未降           | 产能去化尚未充分兑现     |
| 第二步 | 能繁母猪与仔猪供应都下降           | 未来供应收缩概率提高     |
| 第三步 | 商品猪出栏量与出栏重量同时下降     | 供应收缩开始落地         |
| 第四步 | 猪价连续上涨，亏损明显收窄甚至转盈 | 更有理由确认进入反转阶段 |

> 不能只凭某一个月的数据下结论。

## 十一、A 股投资策略：如何提前布局

对于 5 万至 20 万元、持有 1—6 个月的投资者，应重点研究**企业经营质量**，而不是只追求最高弹性。

### 第一类：核心研究对象

#### 牧原股份（002714）

- 养殖规模大
- 完全成本竞争力较强
- 一体化经营体系
- 猪价上涨时利润改善具有规模基础

**主要风险**：市场可能提前反映周期反转，估值过高时股价弹性会下降。

#### 温氏股份（300498）

- 生猪和肉鸡双主业
- 规模化养殖能力
- 经营结构相对多元
- 生猪业务回暖有机会推动利润修复

**主要风险**：禽类业务景气度可能影响整体利润表现。

### 第二类：重点弹性研究对象

#### 神农集团（605296）

- 养殖与屠宰产业链布局
- 养殖成本具有竞争力
- 出栏规模增长
- 周期回暖可能带来利润改善

#### 巨星农牧（603477）

- 生猪养殖规模扩张
- 养殖成本仍有优化空间
- 周期回暖有机会带来利润弹性

#### 天康生物（002100）

- 生猪、饲料和动保业务布局
- 完全成本具有竞争力
- 多业务协同值得研究

## 十二、最终投资结论

关注 2027 年二至四季度，主要有五个原因：

1. 2026 年三季度全国能繁母猪存栏已降至 3602 万头，同比下降 10.7%
2. 能繁母猪到商品猪出栏存在约 10 个月的生产周期
3. 2026 年前三季度猪肉产量仍增长 3.2%，此前高产能形成的供应仍需消化
4. 2026 年养殖行业持续亏损，进一步去产能具备现实动力
5. 多家机构模型均指向 2027 年供应有望改善，但具体兑现季度存在差异

### 时间判断一览

| 时间          | 动作                     |
| ------------- | ------------------------ |
| 2026 年四季度 | 不急于确认反转           |
| 2027 年一季度 | 观察产能变化             |
| 2027 年二季度 | **重点验证供应拐点**     |
| 2027 年三季度 | 重点关注供需改善是否兑现 |
| 2027 年四季度 | 验证猪价反转是否持续     |

> **最看重的不是 2027 年猪价能涨多少，而是 2027 年商品猪实际供应是否真的下降。**

若供应收缩得到验证，低成本、低负债、现金流充足的上市猪企，可能成为这一轮猪周期中更值得研究的投资标的。
