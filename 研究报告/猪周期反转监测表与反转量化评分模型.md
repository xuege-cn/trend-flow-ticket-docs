## 一、核心结论

### 1.1 当前猪周期处于什么阶段？

截至 **2026年11月25日**，判断如下：

> **产能去化已获官方数据确认，但商品猪供给收缩与持续性猪价反转尚未充分确认。**

**主要依据：**

| 维度     | 关键数据                                             | 含义               |
| -------- | ---------------------------------------------------- | ------------------ |
| 能繁母猪 | 2026Q3 末 3602 万头，同比 **-10.7%**，环比 **-4.7%** | 产能去化确认       |
| 生猪存栏 | 42533 万头，同比 **-2.6%**                           | 存栏初步收缩       |
| 出栏量   | 前三季度同比 **+1.4%**                               | 实际供给尚未收缩   |
| 仔猪价格 | 11月中旬同比 **-30.6%**                              | 补栏需求偏弱       |
| 猪价     | 11月中下旬反弹，屠宰端猪肉价仍偏弱                   | 市场验证不足       |
| 养殖利润 | 行业仍亏损                                           | 出清压力未完全消除 |

**阶段定位：**

> 产能去化阶段 → 供给收缩阶段的过渡期；完整周期反转仍需进一步验证。

### 1.2 猪周期反转的核心逻辑

猪周期不是单纯的猪价上涨，而是供给、需求、养殖利润与产能投资共同决定的周期。

**完整传导过程：**

```text
养殖行业持续亏损
        ↓
养殖企业现金流承压
        ↓
淘汰能繁母猪
        ↓
能繁母猪存栏持续下降
        ↓
仔猪出生量减少
        ↓
育肥猪供应逐步减少
        ↓
商品猪出栏量下降
        ↓
生猪价格持续上涨
        ↓
养殖企业利润改善
        ↓
上市猪企业绩反转
```

**指标角色分工：**

| 指标         | 角色     |
| ------------ | -------- |
| 母猪去化     | 领先指标 |
| 仔猪供应     | 中期验证 |
| 商品猪出栏   | 供给验证 |
| 生猪价格     | 市场验证 |
| 养殖利润     | 经营验证 |
| 上市公司业绩 | 最终结果 |

> 不能用其中任何一个指标单独判断整个猪周期。

## 二、产能去化：猪周期反转最重要的领先指标

### 2.1 为什么能繁母猪存栏量最重要？

能繁母猪是生猪产业链的生产源头。一头能繁母猪的变化，会通过繁殖、仔猪育肥和商品猪出栏，逐步传导到未来的猪肉供应。

通常可用约 **9—10 个月** 作为母猪产能变化向商品猪出栏传导的观察周期。

**传导示意（非具体月份供给预测）：**

| 时间         | 产业链变化             |
| ------------ | ---------------------- |
| 2026年1月    | 母猪产能开始减少       |
| 2026年2—3月  | 仔猪出生数量受到影响   |
| 2026年4—5月  | 仔猪供应逐渐减少       |
| 2026年6—8月  | 育肥猪供应开始受到影响 |
| 2026年9—11月 | 商品猪出栏可能逐渐减少 |

### 2.2 中国大陆最近 12 个月能繁母猪数据

**观察区间：** 2025年11月 — 2026年10月

必须区分两种口径，**不可混用**：

| 口径         | 说明                                  |
| ------------ | ------------------------------------- |
| 全国官方统计 | 国家统计局季度末存栏数据              |
| 行业月度监测 | Mysteel、涌益咨询、卓创资讯等样本数据 |

#### A. 全国官方数据及已确认的季度节点

| 时间        | 能繁母猪存栏 | 环比变化  | 同比变化  | 数据属性   |
| ----------- | ------------ | --------- | --------- | ---------- |
| 2025年11月  | —            | —         | —         | 待补       |
| 2025年12月  | 3961 万头    | —         | -2.9%     | 官方年度末 |
| 2026年1—5月 | —            | —         | —         | 待补       |
| 2026年6月   | 3780 万头    | -181 万头 | -263 万头 | 官方季度末 |
| 2026年7—8月 | —            | —         | —         | 待补       |
| 2026年9月   | 3602 万头    | -178 万头 | -10.7%    | 官方季度末 |
| 2026年10月  | —            | —         | —         | 待补       |

**说明：**

- 2025年12月 3961 万头：2025 年年度末公开数据
- 2026年6月 3780 万头：2026 年上半年官方统计披露
- 2026年9月 3602 万头：国家统计局三季度经济数据
- 未列出月份不代表无变化，而是本次未取得可独立核验的全国官方月度绝对值
- **不使用机构样本数据填补官方数据缺口**

**数据来源：** 国家统计局 2026 年三季度经济运行报告；牧原股份 2025 年年报相关行业数据；2026 年上半年官方统计资料。

#### B. 行业样本数据：进一步观察月度去化

根据 Mysteel 相关数据：

| 时点      | 样本能繁母猪存栏          |
| --------- | ------------------------- |
| 2025年7月 | 527.26 万头               |
| 2026年9月 | 478.73 万头               |
| 累计变化  | **-48.53 万头（-9.20%）** |

**分结构：**

| 样本类型     | 起始时间及数量        | 2026年9月数量 | 累计降幅 |
| ------------ | --------------------- | ------------- | -------- |
| 规模化养殖场 | 2025年2月 504.46 万头 | 463.39 万头   | 8.15%    |
| 中小散养殖场 | 2025年2月 17.05 万头  | 15.34 万头    | 10.03%   |

- 2026年8月样本综合环比 **-2.94%**
- 2026年9月环比 **-0.86%**

> 以上均为 Mysteel 监测样本，**不是**全国母猪存栏总量。  
> 来源：Mysteel，2026年10月13日《能繁母猪存栏去化但有限》。

### 2.3 产能去化的判断标准

| 指标         | 弱信号  | 中等信号 | 强信号     |
| ------------ | ------- | -------- | ---------- |
| 母猪连续下降 | 1 个月  | 2—3 个月 | 4 个月以上 |
| 母猪同比降幅 | 0—2%    | 2—5%     | 超过 5%    |
| 母猪累计去化 | 低于 3% | 3—6%     | 超过 6%    |
| 母猪淘汰量   | 正常    | 明显增加 | 持续高位   |

**当前判断：** 已达到较强的产能去化信号。

但仍需关注两点：

1. 母猪数量减少后，养殖效率可能继续提升
2. 规模猪企可能通过提高 PSY、改善成活率、增加出栏体重来抵消母猪减少的影响

> **母猪去化幅度 ≠ 商品猪减产幅度**

## 三、仔猪价格：验证未来供应是否真正减少

### 3.1 为什么仔猪价格重要？

仔猪价格反映养殖企业和散户对未来猪价的预期。

- 若母猪产能已减少，而仔猪价格仍持续下降 → 市场尚未形成明确的未来供给紧张预期
- 若出现止跌、连续上涨、销售量减少、补栏需求改善 → 未来供需关系可能开始改善

### 3.2 最新数据

农业农村部对全国 500 个县集贸市场和采集点监测：

| 指标     | 2026年11月第1周 | 2026年11月第2周 |
| -------- | --------------- | --------------- |
| 仔猪价格 | 17.40 元/公斤   | 16.92 元/公斤   |
| 周环比   | -2.7%           | -2.8%           |
| 同比     | -29.2%          | -30.6%          |
| 生猪价格 | 10.11 元/公斤   | 9.81 元/公斤    |

> 来源：农业农村部畜牧兽医局 2026年11月13日、11月18日市场监测报告。

### 3.3 当前判断

仔猪价格同比下降超过 **30%**，说明仔猪市场仍然偏弱——这是当前反转过程中的重要负面信号。

仔猪价格还受以下因素影响，不完全由母猪数量决定：

- 仔猪成活率
- 养殖户补栏意愿
- 疫病情况
- 规模场内部仔猪调拨
- 育肥利润预期

> 建议将仔猪价格作为**领先指标**，而非单独的反转确认指标。

**反转信号：** 仔猪价格连续 4 周以上上涨，同时仔猪供应量同比下降。

## 四、生猪出栏量：验证商品猪供给是否收缩

### 4.1 为什么出栏量比母猪数量更接近猪价？

母猪存栏是生产能力，生猪出栏是实际供应。市场最终消化的是商品猪，而不是母猪。

判断反转时必须验证：

- 商品猪出栏量是否下降
- 全国生猪出栏量同比是否转负
- 规模猪企出栏量是否下降
- 猪肉产量是否下降

### 4.2 国家统计局最新数据

截至 2026 年第三季度：

| 指标             | 2026年数据 | 同比变化 |
| ---------------- | ---------- | -------- |
| 三季度末生猪存栏 | 42533 万头 | -2.6%    |
| 前三季度生猪出栏 | 53739 万头 | +1.4%    |
| 前三季度猪肉产量 | 4508 万吨  | +3.2%    |

> 来源：国家统计局 2026年10月19日《前三季度经济运行总体平稳，高质量发展取得新成效》。

### 4.3 数据解读

这是目前判断猪周期的**核心矛盾**：

| 方向         | 数据                                    |
| ------------ | --------------------------------------- |
| 产能侧收缩   | 母猪存栏 **-10.7%**；生猪存栏 **-2.6%** |
| 供给侧仍扩张 | 生猪出栏 **+1.4%**；猪肉产量 **+3.2%**  |

说明：当前母猪去化尚未完全传导到实际猪肉供应。未来需观察 **2026Q4 与 2027Q1** 的出栏变化。

**出栏量反转确认标准：**

| 指标           | 初步改善     | 强反转信号                |
| -------------- | ------------ | ------------------------- |
| 生猪出栏同比   | 增速明显下降 | 连续 2 个月或季度同比下降 |
| 猪肉产量同比   | 增速下降     | 连续季度同比下降          |
| 规模猪企出栏量 | 增速下降     | 多家龙头同步下降          |
| 生猪存栏       | 环比下降     | 存栏与出栏同步收缩        |

> 生猪出栏存在季节性，应优先采用**同比**比较，不宜简单比较相邻月份。

## 五、出栏均重：识别压栏和二次育肥

### 5.1 为什么出栏均重很重要？

出栏均重是判断真实供给的重要补充指标。

假设市场有 100 万头猪准备出栏：

| 平均体重 | 对应猪肉量   |
| -------- | ------------ |
| 120 公斤 | 12000 万公斤 |
| 130 公斤 | 13000 万公斤 |

即使出栏头数不变，均重增加也会增加猪肉供应。因此仅观察出栏头数不够。

### 5.2 应跟踪的数据

建议每周跟踪：

| 指标                 | 观察意义               |
| -------------------- | ---------------------- |
| 全国生猪交易均重     | 判断整体出栏体重       |
| 规模场出栏均重       | 判断集团场压栏情况     |
| 150 公斤以上大猪占比 | 判断大体重猪供应       |
| 90 公斤以下小猪占比  | 判断提前出栏情况       |
| 标肥价差             | 判断大猪和标猪供需关系 |

### 5.3 反转信号

真正的供给收缩通常应出现：

1. 出栏量下降
2. 出栏均重不再持续增加
3. 大体重猪占比下降
4. 压栏和二次育肥影响逐步减弱

若猪价上涨但均重持续增加，说明供应可能只是从当前向未来转移。

> 本次未取得截至 11月25日可独立核验的完整全国月度均重序列，因此不填入未经验证的数值。

## 六、养殖利润：判断产能是否真正完成出清

### 6.1 为什么亏损是产能去化的重要推动力？

养殖企业持续亏损会带来：

- 现金流减少
- 负债压力上升
- 低效率母猪淘汰
- 养殖户退出
- 新建猪场投资减少

当亏损持续时间足够长，产能去化才可能从主动调整变为被动出清。

### 6.2 最新养殖利润

截至 2026年11月24日，Mysteel 数据：

| 指标         | 头均利润       |
| ------------ | -------------- |
| 外购仔猪育肥 | **-101.33 元** |
| 自繁自养     | **-213.95 元** |

表明养殖行业仍处于亏损状态。

> 来源：Mysteel，2026年11月24日《国内生猪养殖利润统计》。

### 6.3 如何判断利润反转？

| 阶段     | 利润表现 | 产业含义           |
| -------- | -------- | ------------------ |
| 第一阶段 | 深度亏损 | 产能去化压力增加   |
| 第二阶段 | 亏损收窄 | 行业经营边际改善   |
| 第三阶段 | 扭亏为盈 | 猪价和成本关系改善 |
| 第四阶段 | 持续盈利 | 行业盈利周期形成   |

特别关注上市猪企**完全成本**，建议跟踪：

- 牧原股份
- 温氏股份
- 新希望
- 神农集团
- 巨星农牧

> 不能只看行业平均成本——各家养殖效率、饲料成本、折旧和财务费用差异显著。

## 七、生猪价格：周期反转的最终市场验证

### 7.1 最新猪价数据

不同机构统计口径不同，**不能直接混为一谈**。

截至 2026年11月25日：

| 数据来源     | 日期      | 指标                 | 价格          |
| ------------ | --------- | -------------------- | ------------- |
| 同花顺 iFinD | 11月25日  | 河南外三元生猪       | 10.30 元/公斤 |
| Mysteel      | 11月24日  | 全国外三元出栏均价   | 9.88 元/公斤  |
| 搜猪网       | 11月24日  | 全国瘦肉型猪出栏均价 | 9.62 元/公斤  |
| 农业农村部   | 11月第3周 | 全国活猪均价         | 9.95 元/公斤  |

以上分别属于地区报价、行业样本均价、瘦肉型猪监测均价和全国集贸市场监测均价，不可视为同一价格指数。

### 7.2 近期上涨是否意味着猪周期反转？

搜猪网数据显示：

| 时点        | 价格          |
| ----------- | ------------- |
| 约 11月12日 | ~8.55 元/公斤 |
| 11月24日    | ~9.62 元/公斤 |
| 阶段性涨幅  | **约 +12.5%** |

但同期农业农村部 11月第3周数据：

| 指标             | 变化       |
| ---------------- | ---------- |
| 活猪均价         | 环比 +1.4% |
| 猪肉集贸市场价格 | 环比 -0.2% |
| 猪肉批发市场均价 | 环比 -0.2% |
| 猪肉批发价格同比 | **-17.3%** |

说明：生猪价格反弹尚未充分传导到猪肉消费端。

近期上涨还受以下因素影响：

- 养殖主体出栏节奏放缓
- 二次育肥补栏
- 养殖户惜售
- 腌腊需求季节性改善
- 期货空头回补

> **不能因为 11 月猪价上涨，就直接宣布猪周期已经反转。**

**猪价反转确认标准（建议同时满足大部分）：**

1. 全国生猪均价连续 4 周上涨
2. 累计涨幅超过 10%
3. 全国多数省份同步上涨
4. 猪肉批发价格同步改善
5. 出栏量没有明显增加
6. 出栏均重没有异常增加

## 八、猪周期反转的四个阶段

| 阶段       | 核心特征                 | 重点指标           | 投资意义     |
| ---------- | ------------------------ | ------------------ | ------------ |
| ① 产能去化 | 母猪持续下降、行业亏损   | 母猪存栏、养殖利润 | 提前研究布局 |
| ② 供给收缩 | 仔猪减少、商品猪供应下降 | 仔猪、出栏量、均重 | 关注板块启动 |
| ③ 猪价反转 | 全国猪价持续上涨         | 生猪价格、猪肉价格 | 关注业绩弹性 |
| ④ 盈利反转 | 养殖企业持续盈利         | 完全成本、季度利润 | 趋势确认     |

**产业周期 vs 股票周期：**

| 维度         | 可能出现的阶段               |
| ------------ | ---------------------------- |
| 股票价格     | 可能在第一阶段就开始反映预期 |
| 现货猪价     | 多在第二、第三阶段反转       |
| 上市公司利润 | 多在第三、第四阶段才明显改善 |

> 研究猪周期时，要把**产业周期**和**股票价格周期**分开。

## 九、猪周期反转量化评分模型

### 9.1 模型设计

建立 **100 分制** 猪周期反转监测模型，六个核心指标：

| 指标             | 权重       | 核心用途     |
| ---------------- | ---------- | ------------ |
| 能繁母猪产能去化 | 30 分      | 领先判断     |
| 仔猪价格和供应   | 15 分      | 中期判断     |
| 生猪出栏和存栏   | 20 分      | 供给验证     |
| 出栏均重         | 10 分      | 供应质量验证 |
| 生猪价格         | 15 分      | 市场验证     |
| 养殖利润         | 10 分      | 盈利验证     |
| **合计**         | **100 分** | —            |

### 9.2 各项评分标准

#### A. 能繁母猪去化（30 分）

| 判断条件                            | 分值 |
| ----------------------------------- | ---- |
| 存栏同比增长                        | 0    |
| 存栏同比下降 0—2%                   | 8    |
| 存栏同比下降 2—5%                   | 15   |
| 存栏同比下降 5—8%                   | 22   |
| 存栏同比下降超过 8%，且环比连续下降 | 30   |

辅助判断：若母猪下降但 PSY 持续提升，应适当降低有效产能去化评分。

#### B. 仔猪价格（15 分）

| 判断条件                   | 分值 |
| -------------------------- | ---- |
| 仔猪价格同比下降超过 20%   | 0    |
| 仔猪价格止跌               | 4    |
| 连续 4 周上涨              | 8    |
| 仔猪价格同比转正           | 12   |
| 价格上涨且仔猪供应同比下降 | 15   |

#### C. 商品猪供给（20 分）

| 判断条件                       | 分值 |
| ------------------------------ | ---- |
| 出栏同比继续增长超过 5%        | 0    |
| 出栏增速明显放缓               | 5    |
| 出栏同比接近零增长             | 10   |
| 出栏同比下降                   | 15   |
| 出栏连续收缩且猪肉产量同步下降 | 20   |

#### D. 出栏均重（10 分）

| 判断条件                   | 分值 |
| -------------------------- | ---- |
| 均重持续增加、大猪占比上升 | 0    |
| 均重高位企稳               | 3    |
| 均重连续下降               | 6    |
| 均重下降且大猪占比同步下降 | 10   |

#### E. 生猪价格（15 分）

| 判断条件                               | 分值 |
| -------------------------------------- | ---- |
| 价格持续下跌                           | 0    |
| 价格止跌企稳                           | 4    |
| 连续 4 周上涨                          | 8    |
| 累计涨幅超过 10%，多数地区上涨         | 12   |
| 猪价、猪肉批发价同步上涨，供给同步收缩 | 15   |

#### F. 养殖利润（10 分）

| 判断条件             | 分值 |
| -------------------- | ---- |
| 亏损持续扩大         | 0    |
| 亏损明显收窄         | 3    |
| 自繁自养接近盈亏平衡 | 5    |
| 自繁自养扭亏         | 8    |
| 自繁自养持续盈利     | 10   |

### 9.3 总分对应的周期阶段

| 总分      | 周期状态 | 解释                 |
| --------- | -------- | -------------------- |
| 0—20 分   | 供给过剩 | 反转条件不足         |
| 21—40 分  | 产能去化 | 处于底部酝酿         |
| 41—60 分  | 反转验证 | 供给改善，但仍需验证 |
| 61—75 分  | 初步反转 | 供需关系明显改善     |
| 76—90 分  | 趋势反转 | 周期反转基本确认     |
| 91—100 分 | 强势周期 | 盈利和价格形成共振   |

> 该模型是研究用评分体系，**不是**经过统计回测的预测模型，也不代表未来猪价概率。建议每周更新；母猪存栏与国家统计局数据发布时再做月度/季度修正。

## 十四、最终研究结论

综合母猪产能、仔猪价格、生猪存栏、商品猪出栏、猪价和养殖利润六大维度：

1. **产能侧：** 已出现比较明显的产能去化。2026Q3 末能繁母猪存栏同比 **-10.7%**，是非常重要的领先信号。
2. **供给侧：** 前三季度生猪出栏同比仍 **+1.4%**，猪肉产量同比仍 **+3.2%**，实际供给尚未完全收缩。
3. **市场侧：** 11 月生猪价格阶段性上涨，但仔猪价格仍同比下跌超 **30%**，猪肉批发价格也未同步持续上涨。

> **现阶段不宜简单认定猪周期已经完成反转。**

### 未来最值得关注的三个验证信号

1. 2026Q4 能繁母猪存栏是否继续下降
2. 2026Q4 至 2027Q1 商品猪出栏量是否开始同比下降
3. 生猪价格上涨能否脱离压栏、二次育肥和季节性消费刺激，转变为持续的供需驱动上涨

若三个条件逐步满足，猪周期反转的可信度将显著提高。

### 核心判断

> **2026 年已出现较强的产能去化信号；2027 年是观察产能去化能否充分转化为商品猪供应收缩的重要年份。真正的周期反转，需要供给、价格和利润三个维度形成共振。**
