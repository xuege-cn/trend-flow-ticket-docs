## 辞退补偿的三种情形：N / N+1 / 2N

### 情形一：合法解除（无过失性辞退）——主张 N 或 N+1

适用：不胜任工作（需经培训或调岗仍不胜任）、医疗期满、客观情况重大变化等，且公司履行了法定程序。

- **N**：按本单位工作年限，每满一年一个月工资；六个月以上不满一年按一年；不满六个月半个月
- **N+1**：公司未提前30天书面通知、要求立刻走人时，除 N 外再付一个月"代通知金"
- **计算基数**：离职前12个月平均应发工资（含奖金、津贴、补贴）

### 情形二：违法解除——主张 2N

适用：没有任何法定理由，或理由不成立（如业绩不达标但无考核证据、辞退孕期女职工、口头随意辞退）。

- 可要求继续履行合同，或要求支付赔偿金 2N
- 法律上没有"2N+1"，公司提这个说明不专业或想糊弄你

### 情形三：协商一致解除

- 公司先提出并达成一致 → 支付 N
- 你主动辞职 → 通常没有补偿

### 常见误区

| 误区 | 正确理解 |
|---|---|
| "2N+1" | 法律上没有，只有 N、N+1、2N |
| 补偿按基本工资算 | 按离职前12个月平均应发工资 |
| 签了字也能反悔 | 签了"结清""再无争议"，后续维权非常被动 |
| 口头辞退也算数 | 应要求书面解除通知 |
